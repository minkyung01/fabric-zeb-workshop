# 12. 마무리

[목차](../README.md) \| 이전: [11. 승인과 반영](11-approval.md)

공공 인증 데이터와 현장 데이터를 연결해 D단지의 본인증 위험을 찾고, 근거를 확인하고, 담당자 승인으로 보완안을 반영했습니다. 마지막으로 **만든 결과를 확인하고 실습 중인 감시·실행을 멈춥니다.** 항목 삭제와 Fabric 용량 일시 중지는 관리자 안내에 따릅니다.

**시작 전:** 11장의 승인·결과 확인·Operations agent Stop을 마쳤는지 확인합니다. 결과를 확인하려고 승인 Notebook이나 02장을 다시 실행하지 않습니다.

## 1. 만든 것 확인하기

| 장 | 만든 것 | 확인할 결과 |
|---|---|---|
| 02–03 | Bronze 21개 | 공공 인증 4종(ZEB 9,760행 등)을 Notebook으로 내려받아 원천 그대로 저장하고, Contoso 내부 16개 테이블을 만들었습니다. |
| 04 | Silver 21개 | 시도·용도·등급 표기를 통일하고, 같은 건물을 묶고(25,362개), 발주 이벤트를 반영했습니다. |
| 05 | Gold 22개, ops 3개 | 업무 데이터(Gold)와 판정 결과(ops)를 나눠 저장했고, D단지가 예상 5등급으로 위험임을 확인했습니다. |
| 06 | Ontology `ont_zeb` | 시스템별 코드·인증 설계안·등급 판정·일정 연쇄 규칙을 담았습니다. |
| 07 | Data agent `da_zeb`, `05_answers` | 질문 8개의 답을 정답 Notebook과 비교했습니다. |
| 08 | `sm_zeb`, `rpt_zeb` | 직접 만든 ZEB 인증 현황 페이지와 Copilot으로 생성한 현장 컨트롤 타워 페이지가 있습니다. |
| 09 | `eh_zeb`, `oa_zeb`, `06_risk_event` | 추천 보완안 `OPT-D2`(2억 3천만 원, 41.4% → 4등급)를 Teams로 제안받았습니다. |
| 10 | (선택) `fa-zeb` | Fabric IQ로 Ontology에 근거를 다시 물었습니다. |
| 11 | `nb_apply_decision` | 승인 → 조치 기록 → 설계안 V4 → 4등급·정상 → 이벤트 `resolved`까지 반영했습니다. |

같은 Gold 데이터의 근거를 **정답 Notebook·보고서·에이전트에서 비교**했고, 결정은 담당자가 Teams에서 했습니다. 추천은 Notebook 계산으로 정하고, AI의 설명은 그 계산과 대조했습니다.

## 2. 감시와 실행 멈추기

1.  작업 영역 `zeb-p001`에서 `oa_zeb`를 엽니다. 도구 모음에 **Start**가 보이면 멈춘 상태입니다. **Stop**이 보이면 **Stop**을 누릅니다.
2.  열려 있는 Notebook에 활성 Spark 세션이 남아 있으면 **Stop session**을 누릅니다.
3.  Foundry 에이전트 `fa-zeb`(선택)는 질문할 때만 모델을 호출합니다. 새 질문을 보내지 않습니다.

**확인할 결과:** `oa_zeb`에 **Start**가 보이고 활성 Spark 세션이 없습니다. **Operations agent Stop과 Fabric 용량 일시 중지는 다릅니다.** 유료 용량의 비용 관리는 관리자에게 확인합니다.

## 3. (관리자 안내 시) 실습 항목 삭제

실습 항목은 관리자가 한 번에 지웁니다([관리자 준비 가이드](../admin/README.md)의 "종료 후 정리"). **직접 삭제하라는 안내를 받은 경우에만**, 아래 순서로 지웁니다. 다른 참가자의 항목은 삭제하지 않습니다.

1.  `oa_zeb` → `eh_zeb` → `rpt_zeb` → `sm_zeb` → `da_zeb` → `ont_zeb`. 항목의 **…** → **Delete**를 누릅니다. `ont_zeb`를 지우면 함께 만들어진 `ont_zeb_eh_…`, `ont_zeb_graph_…`도 지웁니다.
2.  Foundry: `fa-zeb` 에이전트를 지웁니다. 프로젝트·리소스는 관리자가 지웁니다.

## 마무리 완료 기준

실습 결과와 승인 근거·반영 결과를 확인했고, 본인의 감시·실행을 중지했으면 완료입니다.
